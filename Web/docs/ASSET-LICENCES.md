# Asset licences and credits

## Summary

**AERODRIVE bundles no third-party creative assets.** Every model, texture, road marking, terrain
colour, sky gradient and sound effect in this build is generated by the code in this repository at
runtime. There are no `.glb`, `.png`, `.jpg`, `.mp3`, `.ogg` or `.wav` files in the project, and
`public/` contains exactly one file: a hand-written SVG favicon.

That is not a limitation that was worked around — it is the reason the project has no licence
questions to answer and no attribution obligations for creative work.

### Assets from Three.js

`three/addons/utils/BufferGeometryUtils.js` (`mergeGeometries`) is imported from the Three.js
package to merge procedural prop geometry. It is part of Three.js and covered by its MIT licence.
No Three.js _example assets_ (models, textures, environment maps) are used.

## Procedural assets — what the code generates

Everything below is produced at runtime by the code shown, and is therefore original to this
project:

| Asset                                                | Generated by                                        | Notes                                                                               |
| ---------------------------------------------------- | --------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Terrain                                              | `src/terrain/heightfield.js`                        | Value-noise fbm + ridged fbm, deterministic from a per-map seed.                    |
| Terrain colours                                      | `terrainColour()` in the same file                  | Height- and slope-driven vertex colours; no texture fetch.                          |
| Road surface texture                                 | `createRoadTexture()` in `src/roads/RoadNetwork.js` | Canvas-drawn asphalt grain, edge lines and a dashed centre line.                    |
| Road geometry                                        | `buildRibbon()`                                     | Catmull-Rom curve swept into a ribbon.                                              |
| Trees, rocks, bushes, buildings, streetlights, signs | `src/world/props.js`                                | Primitive compositions (cylinders, cones, boxes, icosahedra), merged and instanced. |
| Vehicle bodies and wheels                            | `src/vehicles/VehicleFactory.js`                    | Lofted profiles per vehicle class.                                                  |
| Sky, fog, sun and ambient light                      | `src/rendering/Environment.js`                      | Gradient sky shader plus analytic lights.                                           |
| Engine, tyre, wind and ambience audio                | `src/audio/AudioEngine.js`                          | Web Audio oscillator stack, filtered noise buffers and gain automation.             |
| UI, HUD dial and minimap                             | `src/ui/*`, `src/styles/main.css`                   | HTML, CSS, Canvas 2D and inline SVG.                                                |
| Favicon                                              | `public/favicon.svg`                                | Hand-written SVG.                                                                   |

### Determinism

Procurement of "assets" here means seeded generation, and each map's seed is fixed in
`src/world/maps.js` (`alpine-valley-2026`, `coastal-highway-2026`, `modern-city-2026`,
`desert-proving-2026`). The same seed always produces the same terrain and the same prop layout,
which is what makes the world reproducible for testing and screenshots.

## Branding

The name **AERODRIVE**, the wordmark, the colour palette (`#ff5a1f` accent, `#0b0f14` background)
and the tagline are original to this project and provisional. They are defined in
`index.html` and `src/styles/main.css`, so rebranding is a text edit rather than a code change —
the wordmark appears only in `index.html`, the `<title>`, and `public/favicon.svg`.

## Provenance statement

AERODRIVE is an original work inspired by the _concept_ of open-world driving sandboxes. It
contains no code, models, textures, sounds, maps, logos or other assets from BeamNG.drive or any
other commercial title. Nothing in this repository was decompiled, extracted, or otherwise derived
from a third-party game.

## Asset sources considered and not used

The project was scoped to generate its art so that it could ship without a licence inventory.
If that changes, these are the sources that were considered, each of which needs its own licence
check **per asset** before inclusion:

- **Kenney** (<https://kenney.nl>) — CC0; useful for low-poly vehicles and street furniture.
- **Poly Haven** (<https://polyhaven.com>) — CC0 textures and HDRIs; would need conversion to a
  web-friendly format and a size budget.
- **OpenGameArt** (<https://opengameart.org>) — licences vary _per submission_, including
  share-alike and attribution requirements; each asset would need the licence recorded next to it.
- **Blender** (<https://blender.org>) — for authoring original models; CC-BY-compatible output.

No asset from these sources has been downloaded or included. Any future addition must be recorded
in the table above with its exact source URL and licence.
